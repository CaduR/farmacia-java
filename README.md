1. PROJETO: farmacia-java
-----------------------------------------------------------
Arquivos Principais:
- Item.java: Modelo de dados (Nome, Quantidade, Tipo).
- BancoDeDados.java: Lógica de salvar/ler no arquivo .txt.
- Main.java: Onde o código é executado.
- medicamentos.txt: Onde os remédios ficam salvos.

Como Testar:
- Abra Main.java -> Clique no 'Play' verde ao lado do método main.
- O resultado aparece no terminal do IntelliJ.
